# Execution plans

Multi-step work gets a plan in `docs/exec-plans/active/<date>-<slug>.md` using
`docs/exec-plans/TEMPLATE.md`. The plan is the agent's memory across sessions: update it as
steps complete and as you learn things. Move it to `completed/` when the work ships.

A plan has: goal, acceptance criteria, steps with status, evidence gathered, open questions,
and what was learned that should change docs or rules.
